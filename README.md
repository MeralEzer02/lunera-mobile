# 📱 Lunera Mobile

Lunera, kullanıcıları fiziksel görünüş yerine **kişilik uyumu üzerinden eşleştiren** bir mobil uygulamadır.

Bu repository, uygulamanın **frontend (client)** tarafını içerir.

---

## 🚀 Amaç

Kullanıcıların:
- Kolayca kayıt olması
- Eşleşmeleri görüntülemesi
- Kabul / reddet işlemlerini yapması
- Basit ve modern bir deneyim yaşaması

---

## 🧰 Teknolojiler

- React (Vite)
- Axios
- Modern UI (responsive + mobile-first)

---

## 📱 Özellikler

- 🔐 Login / Signup
- 👤 Profil görüntüleme
- 🔎 Match listesi
- ✅ Accept / Reject işlemleri
- ⚡ Hızlı ve sade UI

---

## 🔄 Backend Entegrasyonu

Frontend, aşağıdaki prensiple çalışır:

- Her action → API call
- Response → state update
- Hata → kullanıcıya uygun mesaj

---

## ⚠️ Hata Yönetimi

- 400 → kullanıcı hatası
- 404 → veri bulunamadı
- 409 → çakışma (concurrency)
- 500 → sistem hatası

---

Bu proje MVP odaklıdır:

- Minimal feature set
- Hızlı geliştirme
- Backend ile %100 uyum
